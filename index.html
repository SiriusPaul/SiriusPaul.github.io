About

I'm an undergraduate researcher at USTC MIRALab, advised by Prof. Jie Wang. My work focuses on building agentic AI systems that can reason, plan, and learn from experience.

Currently I'm working on credit assignment for multi-step tool-using agents and LLM-guided adaptive tuning for solver configuration. I'm also exploring on-device LLM agent frameworks for mobile platforms.

Projects

2026.2 — 2026.5

CreditFlow: Dependency-Aware Credit Assignment for Multi-Step Tool-Using Agents

  • Proposed artifact-based credit attribution as the core contribution: treating intermediate artifacts as the fundamental unit for assigning credit in tool-using agent trajectories
  • Designed CreditFlow framework representing rollouts as auditable artifact dependency graphs with explicit producer-consumer links
  • Decomposed training feedback into local transition quality, responsibility transfer for upstream errors, and path-based terminal credit through validated dependency paths
  • Achieves 9.1% average improvement over AgentFlow (ICLR 2026 Oral) while reducing inference steps by 28.6% across 8 benchmarks
2025.10 — 2026.4

LEAT: LLM-Guided Experience-Aware Adaptive Tuning for MIP Solver Configuration

  • Designed and implemented a hierarchical experience repository that summarizes similar historical tuning trials into high-level nodes
  • Built graph construction and hierarchical retrieval mechanisms for efficient LLM-guided experience lookup
  • Outperforms default configuration with over 70% win rate across all tested datasets in one-shot setting
  • Achieves stronger early-stage and final performance under iterative tuning with only 40%—60% of the evaluation budget
  • Framework deployed in industrial applications; a national invention patent has been filed
2026.1 — 2026.3

ASC26 Supercomputing Competition — World Model Acceleration

  • Member of USTC SwanGoose team; accelerated UniFoLM-WMA-0 world model on 4×8 A100 node
  • Implemented high-level feature caching for diffusion models (inspired by DeepCache, CVPR 2024)
  • Combined cross-attention KV cache optimization with parallel execution strategies
  • Achieved 3.7× speedup over baseline while preserving output quality
